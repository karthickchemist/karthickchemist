# Exact Reference README

The uploaded dashboard image is the source of truth for this build.

The README reconstructs the same composition from 11 horizontal animated modules. Every visible module is a GIF; no visible module is a static PNG/JPG.

Animation is intentionally subtle so the composition remains visually identical:
- scanline sweep
- travelling energy line
- pulsing system indicators
- edge signal pulses

The original portrait from the supplied reference is preserved exactly as provided in the source image.

## GitHub limitation
GitHub READMEs do not execute arbitrary page-level CSS/JavaScript. Therefore the animation is implemented using GitHub-renderable GIF assets rather than browser JavaScript.
