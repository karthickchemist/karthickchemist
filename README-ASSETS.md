# GitHub README assets

All SVGs in this folder are local assets used by `README.md`.

Replace the placeholder GitHub username `KarthickV` in README.md with the exact username for the profile.

GitHub README files cannot execute React, Three.js, GSAP, Framer Motion, or autoplay a background video. The animated SVG assets here use GitHub-compatible SVG animation where supported, while keeping the README itself native to GitHub Markdown.

If you later create a cinematic companion website, keep it separate from this README package rather than trying to force JavaScript/WebGL into GitHub Markdown.
