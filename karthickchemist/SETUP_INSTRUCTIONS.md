# How to use this README on your GitHub profile

1. Create a new repository on GitHub with the **exact same name as your username**:
   `karthickchemist/karthickchemist` (this is the special "profile README" repo). Make it **public**.
2. Upload everything in this folder to the root of that repo — keep the folder structure exactly as-is:
   - `README.md`
   - `assets/hero-banner.svg`
   - `.github/workflows/snake.yml`
3. Commit to the `main` branch.

## Turning on the snake contribution graph
The animated snake that "eats" your contribution graph is generated by a GitHub Action (`.github/workflows/snake.yml`), not a static image — GitHub doesn't let any external site regenerate it live for you, it has to run inside your own repo.

- Once you push `.github/workflows/snake.yml`, go to your repo's **Actions** tab and manually run the "generate-snake" workflow once (or just wait — it also runs automatically every day and on every push to `main`).
- It will create an `output` branch in your repo containing `snake.svg` and `snake-dark.svg` — the README already points to `https://raw.githubusercontent.com/karthickchemist/karthickchemist/output/snake.svg`, so once that branch exists, the snake will show up automatically. No README edit needed.
- If your repo's default branch isn't `main`, update the `branches:` line in `snake.yml` to match.

## Style notes
- Pure black (`#000000`) background on the hero banner, bright yellow (`#FFE600`) — punchier than the portfolio's `#FAD22A`, tell me if you want it toned back down.
- Minimal layout: no section-divider clutter, just banner → typing line → one-liner bio → stack → stats → snake → socials.
- Typing animation, hero banner, and snake graph are the only "extra" elements — everything else is plain and clean.

- Update the `mailto:youremail@example.com` link with your real email.
- Update/remove the Instagram, X (Twitter), LinkedIn links to match your real handles.

- Theme colors match your portfolio site: black (`#111111`) background with cyber-yellow (`#FAD22A`) accents.
- Uses `readme-typing-svg` for the animated typing effect and `capsule-render` for the animated wave banners — both are free, no API key needed.
